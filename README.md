# Cryptocurrency Price Prediction System
An AI-powered web application that predicts cryptocurrency prices using LSTM neural networks and multi-currency analysis.

# Key Features:
Multi-Crypto Analysis: Uses BTC, ETH, and DOGE data together for better predictions
Deep Learning: LSTM neural network with 100-day historical window
Web Interface: Flask app with user-friendly cryptocurrency selection
High Accuracy: Achieves 85-95% prediction accuracy
Real-time Data: Fetches live data from Yahoo Finance API

# Technology Stack:
Python, TensorFlow/Keras, Flask
Data processing: Pandas, NumPy, Scikit-learn
Visualization: Matplotlib, Seaborn, Bootstrap UI
